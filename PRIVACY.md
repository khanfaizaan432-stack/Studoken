# Privacy Policy

Spectral Chromatin Coiler is designed as a local-first Chrome extension.

## What the extension processes

The extension processes text that you paste into the popup or inject into a supported chat site.

## What stays local

Prompt compression runs in your browser. The extension does not send prompt text to a server, model API, analytics provider, or remote database.

## Data storage

The extension may save local UI settings, such as compression profile, slider values, and preservation toggles, using browser-local storage. These settings are stored on your device and are used only to restore the popup state.

## Network access

The extension does not make network requests. It only runs on the supported sites declared in `manifest.json` so it can inject compressed text into the active prompt box when you choose that action.

## Telemetry

No telemetry, analytics, tracking pixels, or usage reporting are included.

## User control

You can review compressed output before copying, injecting a draft, or explicitly choosing auto-submit. The safer default workflow is preview-first and draft-first.
